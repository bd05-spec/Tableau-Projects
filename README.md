# Tableau Analytics Projects

This repository brings together Tableau dashboards built around operational and public-interest questions. Each project pairs a Tableau workbook with its supporting data files; the India Lok Sabha project includes several CSV inputs and is provided as a `.twb` workbook.

## Project guide

| Project | What the dashboard explores | Main files |
| --- | --- | --- |
| [Airport Accident Analysis](<Airport Accident Analysis/>) | Accident patterns by year, airport location, phase of flight, purpose, aircraft damage, and US accident category or state. | [Tableau workbook](<Airport Accident Analysis/Airport Accident Analysis.twbx>), [airport accident data](<Airport Accident Analysis/Airport Accident Data.xlsx>) |
| [Electric Vehicle Dashboard](<Electric Vehicles Dashboard/>) | Electric-vehicle population by make, model, model year, state, electric range, battery type (BEV/PHEV), and CAFV eligibility. | [Tableau workbook](<Electric Vehicles Dashboard/Electric Vehicle Population Data Analysis.twbx>), [vehicle population data](<Electric Vehicles Dashboard/Electric_Vehicle_Population_Data.csv>) |
| [Financial Loan Dashboard](<Financial DashBoard/>) | Lending portfolio overview, including loan issuance and good/bad loan breakdowns by grade, term, and geography. | [Tableau workbook](<Financial DashBoard/Financial Loan Dashboard.twbx>), [loan data](<Financial DashBoard/Financial Loan Data.csv>) |
| [India Lok Sabha Election 2024](<Indian Elections Analysis/>) | Election results across constituencies and states: seats and votes won, candidates, party performance, and INDIA/NDA alliance comparisons. | [Tableau workbook](<Indian Elections Analysis/India Loksabha Election 2024 - Final.twb>), [constituency details](<Indian Elections Analysis/constituencywise_details.csv>), [constituency results](<Indian Elections Analysis/constituencywise_results.csv>), [party results](<Indian Elections Analysis/partywise_results.csv>), [state results](<Indian Elections Analysis/statewise_results.csv>), [states](<Indian Elections Analysis/states.csv>) |
| [Vehicle Insurance Cross-Sell Analysis](<Vehicle Insurance Sell Analysis/>) | Customer interest in vehicle insurance, explored through customer and vehicle attributes such as age, gender, driving history, and vehicle damage. | [Tableau workbook](<Vehicle Insurance Sell Analysis/Vehicle Insurance Cross Sell Analysis.twbx>), [vehicle insurance data](<Vehicle Insurance Sell Analysis/Vehicel Insurance Data.csv>) |

## Open a project

Install Tableau Desktop or Tableau Public and open the `.twbx` or `.twb` workbook. A packaged workbook (`.twbx`) may include a Tableau extract; the CSV and Excel files in the project folders are also provided as supporting data. The India election workbook is `.twb`, so keep its supporting CSV files available when opening or refreshing it.

## Scope and interpretation

These dashboards are portfolio analyses of the files included in each project folder. Data coverage, field definitions, and update dates vary by project; check the workbook and source data before treating a comparison as current or causal. No claim of a live data connection is implied.
